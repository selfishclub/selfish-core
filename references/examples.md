# 완성 예시 3종

사용자가 예시를 요청하거나, 답이 막혀 감이 안 잡힐 때 보여준다.
**자기 유형과 같은 예시 하나만** 보여주는 게 좋다. 셋을 다 보여주면 오히려 혼란스럽다.

---

## 유형 1 · 제품이 있는 사람

### 필라테스 스튜디오 · 3년차

**A · 재료**

| 칸 | |
|---|---|
| 하는 일 | 소규모 그룹 필라테스, 8명 정원, 3년차 |
| 남이 나에게 묻는 것 | 문의의 대부분이 *"주차 되나요"*, *"초보도 되나요"* |
| 반복해서 해결한 것 | 운동 시작했다가 두 달 만에 그만두는 사람 붙잡기 |
| 접근 가능한 것 | 회원 40명 · 인스타 팔로워 1,200 · 상담 기록 |
| 지금 상태 | 재등록률 60% |

**B · 제품의 본질**

| 칸 | |
|---|---|
| 형태 | 소규모 그룹 필라테스 수업 |
| **변화** | **Before** 운동 시작을 계속 미루고, 등록해도 두 달을 못 감<br>**After** 주 2회를 몸이 기억하는 상태 |
| 대안 | 홈트 영상 보다 말기 / 헬스장 등록하고 안 가기 / 그냥 미루기 |
| 대체 불가 | 8명 정원이라 강사가 **한 사람도 빠짐없이 자세를 봄** |
| **한 문장** | **"우리는 운동 수업을 파는 게 아니라, 안 빠지는 습관을 판다"** |

> **이 케이스의 발견**
> *"나는 운동을 판다고 생각했는데, 회원들은 습관을 사고 있었다."*
> 문의 1위가 "주차 되나요"였던 이유도 여기서 풀린다 — 퇴근하고 차로 와야 갈 수 있으니까.

---

## 유형 2 · 계획은 있는 사람

### 반려견 산책 대행 · 아직 만들기 전

**A · 재료**

| 칸 | |
|---|---|
| 하는 일 | 회사원, 강아지 2마리 |
| 남이 나에게 묻는 것 | 없음 *(아직)* |
| 반복해서 해결한 것 | 출장 갈 때마다 맡길 곳을 찾아 헤맴 — 본인 문제 |
| 접근 가능한 것 | 동네 맘카페 · 견주 단톡방 2개 |
| 본 것 | 맘카페에 *"산책 좀 부탁드려요"* 글이 **주 2~3회** 올라옴 |

**B · 제품의 본질**

| 칸 | |
|---|---|
| 형태 | 산책 대행 매칭 서비스 *(형태는 아직 유동적)* |
| **변화** | **Before** 출장 때마다 부탁할 사람을 찾고, 맡기고도 계속 신경 쓰임<br>**After** 검증된 사람이 우리 집에 와서 산책시키고, 사진이 온다 |
| 대안 | 지인에게 부탁 / 애견호텔(1박 5만원) / 참고 일찍 귀가 |
| 대체 불가 | 호텔은 **맡기는 것**, 이건 **우리 집 환경 그대로** 두고 산책만 |
| **한 문장** | **"우리는 산책 서비스를 파는 게 아니라, 출장 가면서 마음 안 쓰이는 상태를 판다"** |

> **이 케이스의 발견**
> 형태를 정하기 전에 **변화를 먼저 확정**했다.
> "앱이냐 카톡 채널이냐"는 나중 문제다. *"마음 안 쓰이는 상태"* 가 정해지면 형태는 따라온다.

## 유형 3 · 제품도 계획도 없는 사람

### 세무사무소 10년차 직원

**A · 재료** ← 여기서 씨앗을 찾았다

| 칸 | |
|---|---|
| 하는 일 | 세무사무소 10년, **소상공인 기장 담당** |
| **남이 나에게 묻는 것** | *"이거 경비처리 되나요?"* — 카톡으로 하루에도 몇 번 |
| **반복해서 해결한 것** | 처음 사업자 낸 사람들의 **똑같은 질문**. 홈택스 어디를 눌러야 하는지 |
| 접근 가능한 것 | 소상공인 고객 200명 · **10년치 질문 패턴** |

**씨앗 후보**
1. 처음 사업자 낸 사람이 **첫 1년에 묻는 것들** ← 선택
2. 업종별 경비처리 판단 기준
3. 월별로 챙겨야 하는 세무 일정

**B · 제품의 본질**

| 칸 | |
|---|---|
| 형태 | **아직 미정** — 체크리스트 / 뉴스레터 / 1:1 상담 중 |
| **변화** | **Before** 뭘 모르는지도 몰라서 그냥 넘어가고, 나중에 세금 폭탄<br>**After** 이번 달에 뭘 해야 하는지 알고 넘어감 |
| 대안 | 네이버 검색 / 세무사한테 묻기 미안해서 **그냥 안 물어봄** |
| 대체 불가 | 일반론이 아니라 **10년간 실제로 받은 질문만** 모은 것 |
| **한 문장** | **"우리는 세무 지식을 파는 게 아니라, 몰라서 놓치는 걸 없앤다"** |

> **이 케이스의 발견**
> 아이템이 없던 사람이 **A만 채우고 B로 넘어갔다.**
> 형태가 미정이어도 괜찮다. **변화가 정해지면 형태는 따라온다.**
>
> 그리고 이 사람은 **이미 200명의 고객과 10년치 데이터**를 갖고 있었다.
> 없다고 생각했을 뿐이다.

## 세 유형 비교

| | ① 제품 있음 | ② 계획 있음 | ③ 아무것도 없음 |
|---|---|---|---|
| A의 무게 | 검증 재료 | 근거 | **씨앗 발굴** |
| B 작업 | 검증·재정렬 | 구체화 | **생성** |
| 형태 칸 | 확정 | 유동적 | **미정 OK** |
| 발견 | *"내 가정이 틀렸을 수 있다"* | *"형태 전에 변화를 정했다"* | ***"나한테 재료가 있었다"*** |
