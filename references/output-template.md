# 코어 출력 템플릿

인터뷰가 끝나면 아래 양식으로 **한 장**을 만든다.

## 출력 규칙

1. **빈칸은 빈칸으로 둔다.** 채워지지 않은 칸을 AI가 메우지 않는다.
2. **마지막에 무엇이 비었는지 정리한다.**
3. 파일로 저장할지 물어본다. (`{이름}_코어_v0.1.md`)
4. **가치·페르소나는 만들지 않는다.** 다음 단계 안내로 끝낸다.

```markdown
# ○○○의 코어

```
코어가 섰습니다. 여기까지가 뿌리예요.

이 위에 주요 가치와 주요 페르소나를 세우시면 됩니다.
그건 따로 프롬프트로 진행하시면 돼요.

비어 있는 칸이 있어도 괜찮아요.
뭐가 비었는지 아는 것 자체가 다음에 뭘 알아봐야 하는지의 지도가 됩니다.
```

위에서 만든 코어를 재료로 쓰라고 안내한다.
